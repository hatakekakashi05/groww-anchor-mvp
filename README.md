# Groww Anchor MVP — Retail SIP Retention Platform

> **Strategic Mandate:** Increase 12-Month Active SIP Retention for first-time mutual fund investors from **~32% to 48%**.

## 🚀 Key Features

1. **Cognitive Milestone Statements**
   - Replaces discouraging raw flat NAV returns with positive reinforcement:
     - Discipline streaks (e.g. "5-Month Investor Streak")
     - Milestone completion progress % (e.g. "25% toward ₹30,000 Emergency Safety Cushion")
     - Long-term compounding growth horizon simulation
2. **Empathetic Behavioral Mirror**
   - Intercepts impulsive, unanchored withdrawals for short-term discretionary expenses.
   - Shows real personal cost: resets consistency streak and delays goal attainment by ~10 months.
   - Offers 1-cycle Snooze as zero-regret alternative.
3. **Elastic Cash-Flow Flex**
   - Protects bank mandates when cash flow is tight.
   - Allows dialing down monthly commitment to ₹500 for 3 months with zero ECS bounce penalties.
4. **Milestone Companion AI Copilot**
   - Powered by Google Gemini 3.5 Flash / Flash Lite.
   - Strictly compliant with SEBI Non-Advisory Regulations (zero stock/fund recommendations).

npm start
